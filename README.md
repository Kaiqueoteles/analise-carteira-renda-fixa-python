# Sistema de Análise de Rentabilidade, Benchmark e Projeção de Carteira de Renda Fixa (Perfil Moderado)

Aplicação desktop em console desenvolvida em Python para gestão e análise de carteiras de investimentos em renda fixa (perfil moderado), com apuração de rendimento bruto/líquido (tabela regressiva de IR), comparativo frente à Selic/CDI e projeção patrimonial para o ano seguinte (N+1).

## Pré-requisitos
- **Python 3.8 ou superior** instalado.
- Não requer instalação de bibliotecas externas (utiliza apenas os módulos nativos `csv` e `os`).

## Como executar
1. Baixe ou clone este repositório.
2. Abra o terminal na pasta onde está o arquivo `analise_investimentos.py`.
3. Execute o comando:
   ```bash
   python analise_investimentos.py
